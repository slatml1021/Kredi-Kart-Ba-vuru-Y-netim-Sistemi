# 💳 Kredi Kartı Başvuru Yönetim Sistemi

Kurumsal bir banka ortamındaki kredi kartı başvuru süreçlerini dijitalleştirmek amacıyla geliştirilen tam katmanlı (Full Stack) web uygulaması.

## 🚀 Proje Hakkında

Bu proje, yaz stajı kapsamında gerçek banka iş akışları örnek alınarak geliştirilmiştir.

Sistem sayesinde;

- Müşteri arama ve kayıt işlemleri
- Yeni kredi kartı başvurusu oluşturma
- Başvuru değerlendirme süreci
- Memur ve müdür rolü yönetimi
- Kredi kartı limit hesaplama
- Dashboard ekranları
- Kimlik doğrulama (JWT Authentication)
- Audit Log ve Login History kayıtları

tek bir platform üzerinden yönetilebilmektedir.

---
