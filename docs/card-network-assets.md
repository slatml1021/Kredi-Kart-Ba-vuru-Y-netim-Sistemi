# Kart ağı görselleri

Kart ürünü (Classic, Gold, Platinum, Platinum Plus) ile ödeme ağı (Visa, Mastercard, TROY) birbirinden bağımsız seçimlerdir. Arayüzdeki ağ işaretleri eğitim ve sunum amaçlı prototipte kullanılır. Üretimde bankanın ilgili kart ağı marka sözleşmesindeki güncel resmî varlık paketi ve kullanım kuralları uygulanmalıdır.
